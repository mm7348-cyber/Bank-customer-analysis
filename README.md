# 🏦 Bank Customer Analysis Dashboard
### Tools Used: Power BI | Excel



## 🔍 Problem Statement
Banks deal with millions of transactions and thousands of customers daily. This project analyzes bank transaction data to understand customer demographics, transaction behavior, and customer segmentation to help the bank make data-driven decisions around retention and revenue growth.



## 📁 Dataset
- **Source:** Bank Transactions Dataset
- **Key Fields:** CustomerID, Age, Gender, Location, TransactionAmount, TransactionDate, Segment (New/Loyal)



## 🛠️ Tools Used
- **Power BI** — 5-page interactive dashboard
- **Excel** — data preparation and cleaning



## 📊 Dashboard Pages

### Page 1 — Customer Demographics
- Customer distribution by age group (31-40 is the largest segment)
- Gender distribution across age groups
- Top cities by customer count — Mumbai, New Delhi, Bangalore lead

### Page 2 — Transaction Overview
- **Total Revenue: ₹1.64 Billion INR**
- Average Transaction Amount: ₹1,570
- Monthly transaction trends (August–October)
- Daily transaction count patterns

### Page 3 — Daily Transaction Analysis
- **143K Loyal Customers** identified
- Top customers by total transaction value
- Highest spending customer: ₹15.6M

### Page 4 — Customer Segmentation (NEW vs LOYAL)
- **879K total customers** analyzed
- Loyal customer revenue: **₹478.79M**
- New customer revenue: **₹1.16 Billion**
- Transaction frequency — NEW: 0.74M | LOYAL: 0.68M

### Page 5 — RFM Analysis
- **Total Revenue: ₹1.64 Billion INR**
- NEW customers: Avg monetary value ₹1,568
- LOYAL customers: Avg monetary value ₹3,353 | Avg frequency 2.14



## 💡 Key Business Insights
- **Loyal customers spend 2x more** than new customers (₹3,353 vs ₹1,568)
- **31-40 age group** is the largest and most active customer segment
- **Mumbai, New Delhi, and Bangalore** are the top revenue-generating cities
- **Mid-month transaction spikes** suggest salary-cycle driven spending behavior
- **New customers generate more total revenue** but loyal customers have higher average spend



## ✅ Business Recommendations
1. **Loyalty program investment** — incentivize new customers to become loyal
2. **Target 31-40 age group** with premium products
3. **Geographic expansion** — focus on top 3 cities while exploring Hyderabad and Pune
4. **Mid-month promotions** — leverage salary-cycle spending spikes
5. **VIP customer program** — protect high-value revenue with dedicated management
